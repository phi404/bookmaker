# 固定した検証原稿

すべてこのハーネス用の自作文章。著作物の転載やユーザー原稿は含めない。

| fixture | 検証したい失敗 |
| --- | --- |
| basic.txt | 標準設定でページが成立しない、複数ページにならない、二重字下げ |
| punctuation.txt | 句読点/閉じ括弧の行頭、開き括弧の行末、リーダ/ダッシュの分断 |
| mixed-text.txt | 欧文・数字の欠落、混植時の極端な詰まり |
| unicode.txt | 結合文字・異体字・絵文字の欠落、原稿のHTML実行 |
| long-chapter.txt | 10万文字の欠落・重複、非決定的なページ分割、UIの停止 |
| empty.txt | 空原稿でクラッシュ、不要な実ページ |
| malformed-markup.txt | 未知/壊れた記法を黙って捨てる |
| page-breaks.txt | 連続・末尾の明示改ページを消す、白ページがPDFと異なる |
| heading.txt | 見出しと次の段落が分離する |
| ruby.txt | 親文字/読みの欠落、行境界での分断、本文との衝突 |

`manifest.json` は段階・原稿ハッシュ・独立した本文/読みの期待ハッシュ・追加検査を持つ。ページ数は空原稿と明示改ページ以外を過度に固定しない。標準版面の品質は目視も必要。

```powershell
node scripts/generate-fixtures.mjs --check
```

新たな再現例はファイルと期待値を追加してよい。生成器のケースとmanifestを一緒に更新し、修正前の失敗を確認する。既存の期待値変更には根拠を記録する。生成コマンドを通常検証から呼ばず、差分を自動上書きしない。
