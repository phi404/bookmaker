# Folaxis

原稿を読み込み、ページを整えてPNG・PDFに書き出すWebアプリです。縦書き、ルビ、圏点、目次、画像や自由ページに対応しています。原稿と素材はブラウザー内で処理します。

[試す](https://phi404.github.io/bookmaker/)

## ローカルで使う

Node.js 22.13以降が必要です。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:5174](http://127.0.0.1:5174) を開きます。変更後は `npm run build` して再読み込みしてください。

## 使い方

原稿を貼り付けるか、TXT・Markdown・DOCXを読み込みます。紙面を確認し、必要な書式やページを調整して「書き出す」から保存します。全ページのPNGはZIPにまとめられます。

作業は自動保存されます。別の端末やURLで続ける場合は、左上の作品名から作業JSONを保存してください。

本文のPDFは画像として出力します。取り込んだPDFは元の文字・図形を保持することもできます。PDF/Xには対応していません。

素材原本や書体もまとめて持ち出すには、「書き出す」から制作データのZIPを保存します。
