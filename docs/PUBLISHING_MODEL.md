# Book Modelとスタイル・範囲の契約

## 正本と生成物

Book Modelを唯一の正本にする。原稿文字列、構成ビュー、生成ページの並びを別の正本として管理しない。原稿⇄モデル⇄GUIの往復と、モデル→組版→ページの生成を分ける。

```text
Book Model（schemaVersion 3）
├─ DocumentTree（schemaVersion 2）
│  └─ Section
│     ├─ Heading / Paragraph → Text / Ruby
│     ├─ PageBreak
│     └─ SpecialPageReference → 定義ID
├─ BookStyle / StyleCatalog
├─ ScopedStyle / RunningElement
├─ SpecialPageDefinition / BookAsset
├─ PageOverride
└─ Source表現キャッシュ / 未完draft / 表示メタデータ
```

型の正本は `src/domain/model.ts` / `contracts.ts`。`Publication` をv3へ昇格してBookModelとして扱い、別の構成順や別ASTを新設しない。sourceは投影、RenderedPagesと章の現在ページ範囲は生成物。処理と保存容器は [ARCHITECTURE](ARCHITECTURE.md)。

## 文書と安定ID

レベル1見出しが章Sectionを開始する。章名は見出し参照から得る。段落・見出し・改ページ・特殊参照・SectionのIDは行番号やページ番号ではない。

前後の同一内容、一意な移動、明確なアンカー間の一段落編集を照合し、IDを単調に発番する。同一内容の数が変わる複合編集など、対応が曖昧な場合は新しいIDにし、以前のScopeを孤立参照として残して診断する。別の章・段落へ推測で付け替えない。完全な編集履歴によるID対応を保証する仕組みではない。

ソースに特殊参照があれば同じ定義IDを指す。参照の位置と詳細定義を分け、移動で奥付の内容・素材・座標を失わない。未知/重複/未完の既知参照は確定モデルへ無理に適用せず、未完draftにする。詳細は [SOURCE_FORMAT](SOURCE_FORMAT.md)。

## スタイルの責務

| 種別 | 意味・現在の属性群 |
| --- | --- |
| Character Style | 太さ・サイズ・字間・方向・数字・圏点。ルビは注釈の構造 |
| Paragraph Style | 字下げ・段落内側/末尾余白・前後空き・揃え・行送り・Keep with next |
| Heading Style | 見出しの意味/レベルを保つ段落系スタイル。文字スタイルを参照可能 |
| Page Style | 組方向・段数/段間・本文サイズ/行送り・部分余白・字数/行数・柱/番号の表示 |
| Section Style | 本文/版面スタイルの参照、章開始条件、版面上書き |
| Book Style | 全体の判型・綴じ・標準本文・余白・用途・紙色・番号/既存柱 |
| Local Override | 選んだ文字・ブロック・Section等の個別変更。解除可能 |

名前付きスタイルは同じ種別の `basedOn` を継承する。循環・不明参照・未対応属性は拒否する。Page/Sectionの部分余白は深く合成し、一つの辺だけ指定して他の辺を失わない。旧カタログにPage/Sectionがなければ既定値を補う。段落/文字の部分指定も同じ種別の中で合成する。

**全スタイルを一つの単純な優先順位列へ押し込めない。** 文字・段落・版面は別の属性群。段落/見出しの名前付きスタイル、元記法からの意味、構造Scope、Localを解決し、文字にはインラインの意味/参照/局所属性も合成する。局所指定の解除は本文・スタイル参照を残して継承へ戻す。原稿の揃えとGUIの揃えはlocalStyleへ一本化し、sourceStyleという別値を保持しない。GUI更新では局所書式・スタイルID・章開始/章書式を原稿へ投影し、原稿更新では囲みが消えた指定を旧GUI値から補わない。書式の変更自体で本文IDを発番し直さず、本文同一性と書式の一致を別に検査する。

版面はBookStyleを基底に、本全体の範囲指定、SectionStyle/Sectionが選ぶPageStyleと版面指定、構造範囲、ブロックの局所版面を解決する。選んだPageStyleがSectionの明示値を打ち消さない。厳密な解決順は `typesetting/publication.ts` と独立した優先順位テストで固定する。

## Scope

| Scope | 保持するもの | 再組版時の意味 |
| --- | --- | --- |
| Book | 本全体 | 全体へ適用 |
| Section / 章 | Section ID | 同じ章/本文セクションへ追従 |
| Block | ブロックID | 同じ段落/見出し |
| BlockRange | 両端のブロックID | 両端の間への構造挿入に追従 |
| UntilSection | 開始ブロックID | その位置から次のSection直前まで |
| Pages | 通しページの開始/終了 | 明示的な物理位置。章へ自動変換しない |
| 文字の局所指定 | インラインの属性/局所書式 | 元文字列を維持し、そのスパンへ適用 |

構造範囲の具体性はBook→Section→BlockRange/UntilSection→Block、同じ具体性は後勝ち、Localが最後。参照切れの設定は残して診断する。GUIに全Scopeを常時列挙せず、対象の仕事に合う範囲だけ開く。

段落・文字・容量を変える版面は組版前に解決する。物理ページの容量変更は、変更→再分割→適用先変更の循環を持つため現在は拒否する。容量を変えない番号/柱の表示・紙色は生成後の `PageOverride` として疎な通しページ配列を保持する。飛び飛びの選択を勝手に連続範囲へ拡大しない。

## 柱と番号

RunningElementは内容・意味的/物理Scope・上/下と小口/ノド/中央等・偶奇・章先頭非表示を持つ。内容は固定文字、書名、著者、章名、見出し、ページ番号の参照。同じ位置の要素は具体性と後勝ちで解決する。旧BookStyleの範囲柱も互換として保持する。

ページに複数章があれば、所有Sectionは先頭の本文ブロック（画像ブロックも含む）で決め、必要なら明示開始面で区切る。章のページ範囲表示は組版結果から計算するため、構造へ固定番号を書き込まない。

印字番号、通しページ、見開きの左右を区別する。表示を始める通しページと開始番号は別。番号の範囲変更で版面の偶奇を変えない。非表示や局所範囲の番号系列も元の通しページ対応を保つ。

## 特殊ページと素材

特殊ページの役割（表題紙/奥付/挿絵等）と表現（template / layout / asset）を分ける。追加UIの種類は仕事でまとめ、表題紙/章扉/奥付は自由ページのテンプレートにする。内部の役割と元テンプレートは保持する。自動目次は動的な参照を生成するためtemplateとして残す。原稿はID参照だけを持ち、定義は意味フィールド・テンプレート・要素・素材参照を持つ。

テンプレートを自由ページへ変換してもIDと構成位置を守り、元のテンプレート/内容を残して復帰できる。自動目次は一つの定義から複数の物理ページを生成し、章名で必要ページ数を先に決めてから番号を解決する。目次の自由化は全生成ページのその時点の参照/番号を固定する。続きは独立した自由ページで、テンプレート復帰は選んだページだけに適用する。動的目次であることを変換後も保証しない。

自由ページのPageElementだけがユーザーの座標を持つ。要素の配列順が重なり順で、固定はlockedに一つだけ保存する。複数選択のID集合は一時的なUI状態で、要素やグループを別の正本として保存しない。複製は別の要素IDを発番し、ページのIDと構成位置は変えない。本文フローの座標・画像の予約枠・印刷情報は生成物。AssetはローカルID、原本、表示画像、PDF元寸法等を保持し、複数の参照で共有する。差し替えは同じAsset IDを保ち、使用中の素材内ページを失う差し替えと参照中の素材削除は拒否する。新規の表題紙・章扉・奥付・外部完成ページはlocalStyleのshowFolio/showHeadsをfalseとし、本の番号/柱を重ねない。既存の明示値を上書きせず、GUIから継承/表示/非表示へ戻せる。

## 生成されるページ

FlowPage（通常本文）、StructuredPage（テンプレート）、LayoutPage（自由ページ）、AssetPage（外部素材）を同じ論理ページ列へ合成する。フロー画像はFlowPage内の生成要素、独立/見開き/外部画像は対応する生成ページになる。

章とページの対応、文字の位置、実効dpi・枠外/溢れ・余白衝突はLayoutから得る。これらを正本の固定ページ範囲や手動座標へ書き戻さない。全ページはプレビューと出力で共有する。

## 拡張するとき

新しい属性は意味・継承・Scope・解除・入力投影・保存互換性・生成結果への反映まで定義する。型を足しただけで対応扱いにしない。将来のタブ/脚注/高度目次/印刷検査は [ROADMAP](ROADMAP.md) から有限の対象へ選び、既存概念で表せるか [CASE_CATALOG](CASE_CATALOG.md) で確かめる。

## 設定テンプレート

BookSettingsPreset（schemaVersion 1 / kind book-settings）は適用時のコピーで、別の本の正本ではない。版面・StyleCatalog・本全体の意味的な柱を持つ。本文、作品名/著者の値、固定文章、素材/自由ページ、本文IDに結び付く範囲、物理ページ例外、履歴、draft、選択は含めない。番号の見た目を再利用しても開始通しページ・開始番号・範囲規則は適用先を保持する。

版面/共通書式/柱・番号を選択して一回で適用する。組み込みスタイルは共通のIDを更新し、テンプレート側の独自IDは参照グラフごと新しいIDへ張り替える。既存の独自スタイルと局所指定、本文ID、作品情報は残す。適用後にテンプレートとの同期はしない。共通Undo/Redoと作業JSONが同じ結果を保存する。

未知の版/属性、循環、参照不足、固定文章の持ち込みは部分適用せず拒否する。未完draft中は適用しない。ファイルはUTF-8で1MiB以内、端末の一覧は20件/2MiB以内。破損した一覧は原値を残し、ファイルでの交換を使える。現在の上限をモデルの保存容量保証へ広げない。

## 綴じ方・階層目次・PDFの参照

綴じ方はBookStyle.bindingにだけ保持し、組方向とは独立する。奇数通しページは右綴じで左、左綴じで右。改丁はどちらも奇数先頭で、左右指定は物理面に従う。左右固定の余白は綴じ方で反転しない。印字番号は物理面を決めない。

自動目次のSpecialPageDefinition.tocはdepth（1〜3）、fontPt（7〜14）、indentMm（0〜8）を持つ。省略時は見出し1、9pt、階層ごと3mm。見出し本文・参照先・確定番号を別に保存せず、同じASTとページ列から生成する。自由化した目次はその時点の文字と番号で固定され、PDFの自動リンク対象から外れる。

PDFのしおりとリンクも生成物。範囲に含まれない見出しの宛先を作らず、残る下位見出しは一番近い含まれる上位見出しへ接続する。上位がなければ最上位にする。目次の印字番号は抜粋用に振り直さない。リンクだけを省く。

## 番号系列・末尾調整・図の説明

SectionPropertiesのnumberStart/numberFormatは番号系列の区切り。開始番号は0〜100000、形式はdecimal/roman/Roman。局所指定と章スタイルを解決し、区切りの章は少なくとも改ページする。最終ページ列の章先頭から印字番号を生成し、目次・柱・PDF参照は同じ列を使う。物理ページの偶奇は変更しない。

BookStyle.pageCountMultipleは1/2/4/8/16。内容がある本の末尾へ必要な実白ページを生成し、正本へ空段落や特殊ページを挿入しない。生成白ページには番号と柱を付けない。

ParagraphProperties.orphans/widowsは1〜10の最少行数。名前付き・章・範囲・段落局所の同じ解決を使う。未指定は1、容量内で満たせない場合は診断して緩める。

SpecialPageDefinition.captionは素材ページのtext/numbered/fontPt（5〜14）。説明は1000文字まで。番号は配置済み参照の順序から生成し、画像枠の内側へ説明用の領域を確保する。本文の座標を正本に追加しない。
