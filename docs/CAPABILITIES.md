# 現在の対応範囲と制約

2026-10-22の印刷用紙・グレースケール出力・構成メニュー・アイコン書式までを反映した一覧。この文書は現在の挙動を定義する。**実装あり**と**この変更状態で検証済み**は別で、最新の合格は [QA](QA.md) からソース指紋を確認する。今後の候補は [ROADMAP](ROADMAP.md) に分ける。

## 確認・出力・端末

PCは左端の原稿/構成/素材、中央の紙面、本/編集の設定。左右は開閉・リサイズ可能。中央は見開き/単ページ/一覧と表示拡大、一時的な集中表示。操作検索・キーボードから既存のビュー/設定/出力へ移れる。ライト/ダークはUIだけを変更し、紙面は不変。紙色は白が初期値。「ページの組み方」は左右の余白と開始面の扱いを選び、余白の数値・番号・紙色・組方向を変更しない。画像レイアウトは1080×1080、1080×1350、1600×900 px相当・16ptを明示選択できる。表示モードと版面規則は独立する。取り込み中は最後の紙面を完成扱いせず出力を待機させる。空原稿は待機表示にし、画像/PDF出力を無効にする。R-42。

保存はタブ間で排他し、別タブの新しい作業を古い保存で上書きしない。素材付きは新しいスナップショットの確定後に参照を切り替える。容量不足/競合時は入力を保持し、自動保存を停止して作業JSONを案内する。Web Locksを使えない環境も停止する。組版の依頼は処理中と最新の保留に集約し、古い結果を完成として表示しない。R-49, R-50。

閲覧用PDFは見出し1〜3の階層しおりと自動目次の内部リンクを持つ。範囲外の宛先は省き、含まれる下位見出しは必要に応じて上位へ繰り上げる。PNGは300dpiで1ページ・全ページ/範囲ZIP・見開き。一括PNGを常設し、対象範囲はPDFと共有する。閲覧用の本文は選択した仕上がり寸法・300dpiのRGB画像PDF。素材PDFの保持を選ぶと、原本の切り抜き・回転・色資源・透過グループをFormとして配置し、本文・その他の装飾は同じページの画像を重ねる。共通ページ列と同じSVGを使い、範囲出力でも通しページの対応を維持する。出力をキャンセルでき、保存/開くリンクを残す。編集・出力対象が変われば旧リンクを消し、処理中の変更を旧内容の完成として保存しない。本文の検索可能な文字・本文フォント埋め込み・PDF/X・ICC色管理・CMYK変換は未対応。印刷用の物理寸法と色・解像度は下記の設定で扱う。

独立した実出力検査はA6/B6/A5、左綴じと階層目次を含む。対象ファイル・件数・範囲PDFは検証manifestと実行記録で確認する。その他の判型はモデル/操作の対応と区別し、最大寸法での大量出力を実測済みとしない。判型・プリセットの変更で本文を変えず、組版プリセット再選択は文字/行送り/余白/自動字数・行数を再設定し、柱・番号を保持する。画像レイアウトは別の明示操作で、余白の規則・寸法・文字・余白・番号を画像向けに変更する。

固定ChromiumではPC、1024px、375px、320pxの操作・画像を検査する。スマホ幅の操作は画面切替・ページ移動・PNG生成まで対象。Firefox/WebKitはPC幅と320pxで初回の空原稿・保存復元・接続断中の編集・複数ページPDF素材・PNG/ZIP/PDF/JSONの保存経路を別途検査する。全操作の同等性や実機Safariの確認には広げない。iOS/Android実機・ソフトキーボード・読み上げ・人間のユーザビリティ調査は未実施。アプリ内ブラウザのPNG準備・リンク確認と、Chromiumの実ダウンロード検査は別の証拠。

## 容量と数値の契約

- 原稿は50万UTF-16コード単位まで。長文検証は10万コードポイントのfixture。ファイル容量制限とは別。
- 任意用紙は幅60–350mm、高さ60–500mm。基本本文7–18pt、行送り倍率1.55–3、余白5–70mm。版面に本文が入らない組み合わせは拒否する。字数/行数1–200は実容量を超えない上限指定。
- 文字局所指定は5–36pt、字間0–1em。自由ページ文字は5–72pt。異なる用途の範囲を同じ上限として扱わない。
- DOCX入力32MiB、本文XML8MiB・対象XML合計12MiB。素材原本1件16MiB、PDF20ページ、PDF表示画像のdata URL累計48MiB。
- 素材100件、特殊ページ200件まで。素材全体は原本と表示画像のdata URL文字数の合計を80×1024×1024以下に制限する。デコード後80MiBやメモリ使用量の保証ではない。
- PNG/ZIP/PDFの圧縮画像累計128MiBで停止する。小分けの範囲出力を使う。これはブラウザの最大メモリを保証する値ではない。

上限の実装は `src/domain/style.ts` / `styles.ts` / `special.ts`、`src/io/import.ts` / `assets.ts` / `raster.ts`。容量上限に達する全組み合わせの負荷試験は未実施。

## 配布と起動

ローカル起動に加えて、GitHub Pagesの静的試用版を配置する。原稿処理と保存は端末内のまま。配下URLで同梱フォント、組版/PDF素材Worker、ZIP/PDFを扱い、リリース・タグは作らない。手順・公開範囲・CIと全体ゲートの違いは[DEPLOYMENT](DEPLOYMENT.md)、R-44へ集約する。実際の配置状態はoutput/deploymentの証拠で確認する。

## 仕上げと持ち出し

章ごとの開始番号と算用数字/小文字・大文字ローマ数字、末尾の白ページによる総ページ数の倍数調整に対応。番号は印字の系列で、物理面・改丁を変更しない。ローマ数字は1〜3999を使い、範囲外は算用数字で表示する。

PNG一括ZIPは分割なし/4枚/10枚ごとのフォルダーを選べる。制作データZIPは再開用JSON、原稿、素材原本、設定、同梱Noto Serif JPとOFLを含み、SHA-256を確認して再開する。原稿等のコピーを編集してもJSONへ自動統合しない。圧縮/展開サイズは192MiB以内、一覧外ファイル・重複パス・危険なパス・不一致は拒否。最大容量での性能保証とは別。

孤立行対策は段落の先頭/末尾に残す最少行数を1〜10で指定する。未指定は従来の流し方。狭すぎる版面では診断して指定を緩め、文字を失わず処理を進める。

組版Workerとの往復は素材の参照と寸法に限定し、表示画像は同じ本から解決する。10万/50万UTF-16単位のNode計測を用意しているが、50万文字の実機ブラウザー操作や全素材上限の同時使用を保証するものではない。

制作データの書体は現在同梱するNoto Serif JPの指紋と照合する。異なる書体を含むZIPは黙って置換せず、現在の作業を保持して読み込みを拒否する。任意のローカル書体の導入とは別の契約。


## 印刷用の汎用PDF

R-64。モノクロ本文は600dpi・DeviceGray・各辺3mm・トンボなし、カラーは350dpi・RGB・各辺3mm・トンボなしを初期値とする。カスタムで塗り足し0〜10mm、トンボなし/角/角とセンター、300/350/600dpi、RGB/グレースケールを指定できる。設定は作業JSONと制作データへ保存し、Undoできる。

MediaBoxは用紙、TrimBoxは原寸の仕上がり、BleedBoxは塗り足し。本文やページ全体を拡大しない。印刷用の本文文字は黒で描く。トンボは塗り足しの外へ0.25ptの黒線で描く。色版合わせのレジストレーション色・カラーバーは付けない。印刷用では閲覧用のリンク注釈/しおりを付けない。

端にある素材・自由要素のうち指定の塗り足しまで届かないものと、低い実効dpiの画像を確認へ出す。画像の画素を伸ばして補完しない。PDF/SVGは原本から印刷時の解像度で一時描画し、元の保存画像や原文は変更しない。素材PDF内部の画像解像度・フォント埋め込み・色の適合まで検査したとはしない。原本の文字/図形を保持する方法はRGBで使い、グレースケールとの併用は拒否する。

1ページ画像または一つの素材PDF展開画像は4000万画素、1ページ内の一時素材画像はdata URL長の合計128MiB以内。最終PDFの圧縮画像/原本累計上限も維持する。端末の最大メモリや最大容量の一括印刷を保証する値ではない。

主要印刷所の比較は[調査記録](research/2026-10-22-print-submission.md)。商品・窓口・色やPDF形式の指定が異なるため、社名だけの入稿可能表示やPDF/X適合表示は行わない。実際の注文受付・印刷見本の検証は未実施。RM-20のICC/CMYK・PDF/Xと、RM-18の本文文字PDFは残る。
