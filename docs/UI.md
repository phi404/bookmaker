# 操作モデルと表示契約

## 操作の思想

**原稿を入れる → 紙面を見る → 本と書式を整える → 必要な範囲だけ調整する → 書き出す。** 内部の構造化を利用者の設定負担へ転換しない。本の構成も複数の編集ビューの一つで、唯一の入口にはしない。

初回は空の原稿入力と短い紙面の待機表示を出す。保存済みの本は復元する。可変幅の16px書体、折返し、行番号なし。「ソース」「Inspector」「Override」は画面ラベルにしない。読み込み・貼り付け・ファイルのドロップと任意のサンプルを入口に置く。空の原稿では画像/PDF出力を無効にし、作業JSONは保存できる。

## PCの役割

| 領域 | 仕事 | 操作 |
| --- | --- | --- |
| 上 | 本全体の作業 | 名前から開くファイルメニュー（新規/開く/作業JSON保存/作品情報）、Undo/Redo、操作検索、表示テーマ、保存状態、右上の書き出し |
| 左端 / 左 | 内容・順序・資源を編集するビュー | 左端の原稿 / 構成 / 素材と、その編集パネル。同じBook Modelと選択を共有 |
| 中央 | 生成された完成物を確認する | 見開き / 単ページ / ページ一覧、表示拡大、対象選択 |
| 右 | 何をどこまで変えるか | 本 / 編集。編集の対象を先頭で選び、範囲への指定を原稿にも表示する |

48pxの上部バー、52pxの左端、薄い境界線、統一されたローカルアイコン、短い操作ラベルを使う。選択・フォーカスに控えめな青紫を使う。常設の説明文や同じ対象名の反復を減らし、記法・制約・操作の説明はヘルプと詳細へ置く。状態・失敗・適用範囲は必要なときに残す。新機能は操作検索にもつなぎ、上部へボタンを増やし続けない。

ライト/ダークはUIの表示設定で、紙色・本文色・版面・出力を変えない。端末内に保存し、Book Modelへ混ぜない。下部の状態欄はローカル処理とページ数を示す。

### 設計上の利用者想定

実ユーザー調査の結果ではなく、現行操作を検討するための想定。

- 初めて同人小説を本にする人：原稿導入、標準設定、紙面確認、PNG/PDFまでを短くする。
- 章・扉・挿絵・奥付を整える人：構成/素材と明示的な対象設定を使い、本文全体へ戻れる。
- 組版の数値を調整する人：詳細・共通スタイル・操作検索・キーボード・集中表示を使う。
- スマホで本文サンプルを作る人：画面切替、単ページ、簡単な設定と出力を使う。

## 原稿・構成・素材

原稿は本文と構造参照を編集する。ルビ/圏点の形/見出し1–3/改ページ/改丁/範囲/文字は必要な操作へつなぐ。珍しい記法や数値は閉じたヘルプ/詳細に置く。表示上の折返し・幅変更は原稿の改行やASTを変更しない。

構成の追加は章・自由ページ・自動目次・素材ページに集約する。表題紙・章扉・奥付は自由ページの開始テンプレートで、追加直後から要素を編集できる。目次は章名の折返し・必要ページ数・確定番号を自動更新する仕事が異なるため独立した入口を保つ。画像・PDF・外部完成ページの入口は素材ページにまとめる。章は内容ごと、特殊ページは参照位置をドラッグして移動する。ドラッグ・Alt+↑/↓・項目メニューの移動先指定は同じ編集履歴を使う。章の現在ページ範囲は生成結果。本文フローから生まれたページをドラッグして構造を並べ替えない。特殊ページの詳細や座標を原稿へ出さない。

素材は複数ファイルを端末内で読み込む。名前・サムネイル・容量/ページ・参照数から選び、画像は一頁、複数頁PDFは範囲を確認して構成の選択位置の後へ挿入する。管理から参照IDを保つ差し替えと未参照素材の削除を行う。参照中の頁を含まない差し替えは拒否する。素材と独立完成ページ、本文フロー画像は区別する。

## パネルと編集幅

左右は独立して端で開閉し、閉じた側の復帰アイコンか左端の編集ビューから戻す。開閉を上部バー右端へ集めない。境界はドラッグと矢印キーで幅変更する。入力位置・選択対象・パネル幅を保持する。

1440pxでは左420px・右280pxを初期値にする。「原稿を広げる」は右を閉じ、戻すと元の幅と右の開閉状態へ戻る。761–1199pxでは左360px・右は初期非表示にし、右を開くと左を一時的に閉じ、紙面の横に場所を確保する。右を閉じると左を戻す。幅1100px以下は単ページを初期にし、PCでは見開きを明示的に選び直せる。

「紙面に集中」は両側を閉じ、戻すと元の開閉状態を復元する。幅や本の設定は変えない。集中状態は一時的で、表示保存へ混ぜない。集中中に編集パネルを開く操作は通常の画面へ復帰する。

### 操作検索とキーボード

Ctrl / Cmd + Kまたは上部の検索で、ビュー・読み込み・章/ページ追加・本文全体・版面詳細・ページ番号・柱・共通スタイル・作品情報・書き出し・ヘルプを探す。既存の操作経路へ接続し、別の編集処理を持たない。↑↓で候補、Enterで実行、Escapeで閉じる。閉じると元の操作位置へ戻る。ルビ・圏点・改ページ・改丁・範囲書式・中央揃えも同じ操作へ接続し、検索を開く前の原稿選択を復元する。Ctrl/Cmd+Sは作業JSONの保存、Ctrl/Cmd+Oはファイルを開く。左端のビューは矢印/Home/Endで切り替えられる。Ctrl / Cmd + Shift + Fは紙面への集中表示。原稿ではCtrl/Cmd+Enterで改ページ、Shiftも押すと改丁、Ctrl/Cmd+Alt+1–3で見出し、Ctrl/Cmd+Bで太字。構成やキャンバスのキーは対象にフォーカスがあるときだけ扱う。入力変換中や別のダイアログを開いているときは割り込まない。

## 本と編集

右パネルの常設タブは「本」「編集」。本は判型・版面・番号・柱、編集は対象に応じた書式やページの内容を扱う。選択の有無をタブの種類にしない。

編集の先頭に一つの「対象」を置く。いまの文章・範囲・章・自由ページ・柱・通しページと、全体の基本・本文・見出し1〜3・引用の共通書式を切り替える。対象の書式を変えることと、共通書式をまとめて変えることを区別する。本文の揃えと太さは折り畳まず、余白・行送り等は詳細で開く。選択しただけでは本の設定やスマホ画面を奪わず、編集を開く明示操作で切り替える。共通書式を表示中の紙面クリックも、その編集先を勝手に変えない。同じ対象のフォーム再生成では既存の詳細の開閉とフォーカスを保つ。変換後に初めて現れる詳細は、その既定の開閉を使う。

全体の標準文字サイズはBookStyle、共通の太さ・字間・英数字・圏点は名前付き文字スタイルに保存する。本文/見出しごとの文字設定は同じカタログの参照を使い、専用の別設定を複製しない。共通スタイルの詳細編集も同じデータを変更する。名前付きスタイルと明示的な局所指定は継承で分ける。

原稿で複数行を選び「範囲」から揃え・太さ・空き等を変更できる。文字選択が複数段落にまたがる場合は範囲編集へ進み、何も選ばず「文字」を押したら全体の書式へ進む。揃えと行送りは選択範囲が触れた段落全体へ適用し、一段落の途中だけを段落として切り裂かない。同じ段落の部分的な文字指定は文字ダイアログを使う。原稿の囲み指定を編集/削除すればGUIの局所指定も変わり、隠れた別値を復活させない。

紙面の本文クリックは対象を記憶し、Shift+クリックで連続した文章の範囲を選ぶ。明示調整または「編集」から設定を開く。適用先は選択範囲/章全体/章末まで/すべての文章。適用先を変えるとその範囲の値を表示し、変更した属性だけを適用する。異なる値は「混在」、未指定は共通書式からの継承と区別し、個別指定だけ解除できる。元本文とルビは保持する。

自由ページは文字・画像・線・矩形を追加し、紙面で移動する。右/下/右下のハンドルでサイズを変え、右パネルで位置・サイズ・揃え・色・線幅・太さを調整する。レイヤーの上が手前。前後/最前面/最背面、複製、固定/解除、削除は同じUndoを使う。固定した要素は移動・サイズ変更・削除を拒否する。文字のダブルクリックは内容の編集へ進む。

紙面の要素は矢印で1mm、Shift+矢印で10mm移動。Ctrl/Cmd+Dで複製、Deleteで削除、Tab/Shift+Tabで要素を巡回、Escapeで要素の選択を外す。座標操作は自由ページだけ。Shift+クリックまたはレイヤーのチェックボックスで要素を追加/解除し、紙面にフォーカスがあればCtrl/Cmd+Aで全要素を選ぶ。複数選択をまとめて移動・紙面に整列・複製・固定/解除・削除でき、1操作でUndoする。固定要素は移動せず、固定を含む削除は全体を拒否する。回転と永続グループ化は未対応。

## 範囲と生成ページ

意味的Scopeを優先する。対象に応じて本・章/セクション・ここから次のセクションまでを示す。選択と範囲を混同しない。章のp.12–23は現結果で、設定の固定ページ番号ではない。

一覧は綴じ方に沿った読書順。チェックボックスとShift範囲/Ctrl・Cmd追加選択を併用する。疎な選択を拡大せず、「通しページへ固定」を明示して装飾例外だけを扱う。容量を変える書式は章/構造範囲から指定する。Scopeの厳密な意味は [PUBLISHING_MODEL](PUBLISHING_MODEL.md)。

単ページは上に前/下に次。見開きは右綴じで左に次/右に前、左綴じで右に次/左に前。キーボードも対応する。通しページの移動欄と印字番号は別。拡大は紙面の読みやすさを変え、ptやmmを変更しない。

## スマホ

PCの3ペインを縮小しない。初回原稿、原稿画面上の原稿/構成/素材、下部の原稿/プレビュー/設定/出力の切替、単ページ、スワイプと縦ナビを基本にする。入力は画面幅いっぱいの16px、パネルの幅変更は出さない。操作検索からも各画面と出力へ移れる。

紙面の対象を押しただけでは画面を切り替えず、明示調整で設定へ移る。一覧でチェックを続けて複数選択し、下部「設定」から編集する。出力は右上と共通のダイアログを開き、閉じたら直前画面へ戻る。

320px/375pxの幅で横はみ出し、タップ対象、ダイアログ、長文、保存/出力を検査する。iOS/Android実機とキーボードは別途評価する。画面幅の合格を実機の合格としない。

## 状態・失敗・出力

読み込み/再組版/出力の状態、保存失敗、未完原稿、破損復元を理解できる表現で示す。未完draft中は最後の有効紙面と別入力を保ち、GUIや書き出しで無断確定しない。

書き出しにはPDF・全ページPNG（ZIP）・表示ページPNG・見開きPNGを示す。全ページ/範囲の対象はPDFと一括PNGが共有する。作業JSONはファイルメニューからも保存できる。新規作成では画像の出力操作を省いた保存画面にJSONの保存リンクを残し、利用者が保存ファイルを確認して「新しい本を始める」を選ぶまでは元の作業を保持する。ダウンロードの中止・画面を閉じる・再読込でも勝手に新規へ移らない。作業が変われば旧ファイルから新規へ進む操作も無効にする。画像レイアウトは左右の余白を固定する場合に正方形・4:5・16:9を選べ、16pt・白い紙・番号なし・余白も一緒に設定する。画面と出力にpxを示す。「ページの組み方」は左右の余白と開始面の扱いを選び、番号・紙色・余白の数値を変えない。長い処理の中止、完了後の保存/開くリンクを用意し、自動ダウンロードだけに依存しない。結果リンクは作業と対象の組み合わせに結び付け、変更後に残さない。出力前に未完原稿・枠外・文字溢れ・素材不足等を一覧にし、該当箇所へ戻れる。欠落はその作業の確認を必要とし、未完原稿は確定するまで出力しない。閉じる操作はスクロール中も上部に残る。

## 検査の接続点

UI接続点は `tests/e2e/ui-driver.mjs`。ラベルは操作の意味を保ち、test idを画面説明へ露出させない。プレビューのlayout-stateとinput/layout revisionが一致し、フォント読込が終わった状態を検査する。

視覚比較は固定環境で行う。基準画像がない初回を自動承認せず、差分と理由を目視する。探索画像は履歴で、現行のUI契約と利用者評価を代替しない。完了条件は [ACCEPTANCE](ACCEPTANCE.md)、結果は [QA](QA.md)。

## 本文の検索・原稿への移動・設定再利用

原稿の検索アイコン、操作検索の「本文を検索・置換」、Ctrl/Cmd+Fで検索を開く。Ctrl/Cmd+Hは置換も開く。本文/記法を文字列として検索し、大小文字の区別、開く前に選んだ範囲への限定、前後移動、一件/全置換を使える。置換文字の記号もそのまま入れ、全置換は一回でUndoする。Enter/Shift+EnterとF3/Shift+F3で一致へ移動し、Escapeで閉じる。IME変換中のEnterを実行として扱わない。

一致する原稿位置を選択し、同じ紙面位置へ対応する色を付ける。未完draft中は原稿検索・置換を使えるが、古い確定紙面へ一致を付けない。検索中の通常操作でスマホの画面を奪わず、「紙面で見る」で明示的に切り替える。正規表現/GREPや紙面への直接入力はこの操作に追加しない。

紙面を一回選ぶと対象だけを記憶する。「原稿で開く」または文字のダブルクリックで、描画した文字に対応する原稿範囲を選ぶ。ルビ親文字はその文字、読みは対応するルビの読み全体、縦中横/横倒しの一まとまりと複合書記素はその単位を扱う。古い位置を編集後の別文章へ適用しない。原稿へ戻る操作は設定の対象選択と分ける。

本のプリセット付近の「設定テンプレート…」から、現在の設定を端末へ保存/ファイルへ書き出し、一覧/ファイルから選び、版面・共通書式・柱/番号を確認して適用する。本文・作品情報・個別指定は保持する。適用は共通Undo、削除は直後の復元を用意し、同名の保存は置き換えと表示する。エラーはダイアログ内に残す。形式/除外対象/上限は[PUBLISHING_MODEL](PUBLISHING_MODEL.md)。

## 通知と本の仕上げ

通知は画面下の独立した表示で、原稿・紙面・設定を押し動かさない。スマホでは下部の画面切替より上に置く。長文は通知本文の内側でスクロールでき、閉じる/読み込みの取り消しは残す。保存失敗や未完原稿の通知を時間で消さない。入力途中の短い状態は原稿下の既存の状態欄に置き、原稿欄の高さを変えない。

本の「ページの組み方」は「見開きで組む」「一枚ずつ組む」。用途名を選ばせず、プレビューの一枚/見開き表示とも独立させる。紙色の標準は白で、温かい白を選ぶこともできる。綴じ方は「版面の詳細」から右/左を選ぶ。

自動目次の設定で、含める見出し1〜3を選ぶ。「目次の文字と字下げ」で項目の大きさと階層の字下げを調整する。PDFには同じ見出しの階層しおりと、目次から本文へのリンクを加える。紙面の本文を別に作り直さない。

読み込み完了などの通知は、通知の外で次のクリック/キー操作を始めたら閉じる。通知の取り消し操作はそのまま利用でき、共通Undoも保持する。検証・保存の失敗は自動では閉じず、閉じる操作を用意する。


紙面は内容を表示するグループと選択の実ボタンを分ける。Enterで選択し、自由ページの矢印操作も維持する。仮想的な対向余白は読み上げ対象にしない。設定タブの閉じる操作はタブ一覧の外へ置き、モバイルの作業切替はナビゲーションとして示す。

## 本の仕上げと制作データ

本の「本の仕上げ」で総ページ数を2・4・8・16の倍数にそろえる。章の編集にある「ページ番号の区切り」は開始番号と算用数字/ローマ数字を指定し、新しいページから始める。解除は開始番号を空欄、表し方を継承へ戻す。

素材ページの「図の説明」で説明のみ/自動図番号付きの説明を選ぶ。図番号は構成順、説明は同じ画像枠に追従する。枠に収まらなければ原文を保持して診断する。本文を自由座標に変えない。

書き出しの「PNGのまとめ方」は選択範囲を4枚/10枚ごとのフォルダーへ分ける。連番は元の通しページ。クレジットは既存の柱や自由ページで紙面へ置き、出力だけの隠れた文字は足さない。

「PDFの詳細」の素材PDF保持は元の文字・図形を埋め込む。本文は画像のまま。注釈/フォーム付きは説明して停止し、画像PDFを選び直せる。

「作業ファイルと原稿」から制作データZIPを保存し、通常の読み込みで再開する。JSONが正本で、同梱の原稿・素材原本・設定は他ソフト向けのコピー。破損したZIPは部分適用せず、開いている本を保つ。

共通書式のUndo/Redoでは、その共通書式の編集先を維持する。履歴を戻しただけで本の設定へ切り替えない。

対象名はピッカーで一度示し、同名の見出しを視覚的に繰り返さない。適用先を全文章/章へ広げたときは、その実際の対象名へ変える。古い保存の完了で新しい入力を保存済みと表示しない。

自由ページの対象はページ名と選んだ文字/画像/線/矩形、または要素数を示す。要素を選ぶとそのプロパティを先にし、追加と重なり順は短い開閉行へまとめる。利用者が重なり順を開いて選び続けている間は、同じページで開いた状態を保つ。ページ単位の装飾と版面は自由ページの詳細に置く。


## 構成メニューとアイコン書式

構成行の「…」に複製・削除・移動先指定を置き、下部の上へ/下へ操作は置かない。ドラッグとAlt+↑/↓を保ち、移動先のダイアログはタッチや長い構成でも使える。章は内容と含まれる特殊ページをまとめて複製する。メニューを開くだけでスマホを設定画面へ切り替えない。

メニューは矢印・Home/End・Escapeを扱い、閉じると対応する項目の操作へフォーカスを戻す。Shift+F10でも開ける。削除は共通Undoへ接続する。

文字の太さ・段落の揃えは同じアイコン部品を使う。ツールチップと読み上げ名を持ち、適用中は押された状態を示す。回転矢印は共通書式への継承で、他の局所指定は消さない。混在時は混在と表示し、一つの値を選択済みに見せない。自由ページの紙面への整列は一回の操作で、段落の揃えとは分ける。

## 印刷用PDF

書き出しの「PDFの設定」は閲覧用／印刷・モノクロ本文／印刷・カラー（RGB）／カスタム。詳しい塗り足し・トンボ・解像度・色・素材PDFの保持は「PDFの詳細」に置く。仕上がりとPDF用紙の寸法、同じページからの用紙見本を示す。PNGの寸法表示とPDFの解像度を混同しない。

設定は作業の一部として保存・Undoする。印刷設定を変えても原稿やページ数を変えない。端の素材が塗り足しまで届かない場合などは、出力前の確認からその要素へ戻れる。設定変更後の古い保存リンクは消す。PDF/X・CMYKや印刷所の受付を確認済みとは表示しない。
