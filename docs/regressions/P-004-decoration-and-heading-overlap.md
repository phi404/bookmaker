# P-004 見出しルビと紙面の補助文字

2026-10-01の拡張確認で発見。テストを先に追加して失敗を確認した。

- 行送り1.55倍・折り返した見出しのルビが、1.15倍の見出し字形と組み合わさって隣の列へ達する。見出しの倍率を行送りの余裕に合わせて下げた。親文字と読みは保持。
- 地余白5mmに番号を端から8mmで置けてしまう。柱も天余白より内側へ指定できる。本文の余白帯に収まらない大きさ・距離を検証して拒否する。
- 同じ上部位置の柱で端からの距離だけが違う場合、前後の範囲指定が同時に描かれる。表示対象を位置と範囲で解決し、後の指定だけを使う。上部ノンブルと同位置にある有効な柱も拒否する。長い複数の柱は共通の余白帯を分け合う。

再現は `tests/product/page-controls.test.mjs` の見出しルビ、余白帯、重複する柱の3テスト。禁則の閾値や既存の本文ハッシュは緩めていない。
