# P-015 ユースケース監査後の操作と出力

2026-10-19。SNS画像、文章だけの本、部分書式、本全体、外部素材を使う本の監査を受けた修正履歴。人間による利用者調査とは分ける。

## 再現

修正前にモデル検査3件が失敗した。見開きの偶数右面に左半分を割り当て、32章の目次を1頁へ置き続け、新規の表題紙等へ本の番号を重ねていた。ブラウザー検査3件でも、自由ページの直接クリックで選択が消え、複数段落の異なる値が継承と同じ空欄になり、編集前の出力リンクが残った。

fixtureはbook-toc-many、book-spread-colors、既存のbook-local-pageとbook-range-format。最初の失敗、context、trace、画面はoutput/ux-improvements-2026-10-19/before-*へ保存した。localhost通信を拒否された検査と、実際のアプリの失敗は区別する。

## 修正の要点

- 見開きの偶数右面に右半分、奇数左面に左半分を置く。左右共通の版面でも見開き素材は同じ対向面へそろえる。
- 章名で目次の分割数を決めてから本文を組み、確定番号を入れる。長い章名・最小用紙も検査する。
- クリックではポインターを即座に捕捉せず、移動開始後に捕捉する。選択時に紙面を動かさず、pointerdownで選択した要素を後続clickで失わない。
- 混在と継承を区別し、変更した属性だけを対象範囲へ適用する。検索前の原稿選択を復元する。
- 出力結果をrevisionと対象に結び付け、変更時にリンクを消す。欠落候補は出力画面から該当頁/要素へ戻せる。確認前の欠落出力と未確定原稿の出力を止める。
- 新規の表題紙/章扉/奥付/外部完成頁の番号と柱をlocalStyleへ一度だけ保存し、表示/非表示/継承を変更できる。

## 関連する操作の検査

画像レイアウト、JSON保存後の新規作成と再開、複数ファイル/PDF範囲導入、参照を保つ差し替え、複数要素の移動/固定/一括削除の保護、狭い画面、スクロール中の出力ダイアログを検査する。実出力の左右は、同じ誤りをするPNG同士の一致だけに頼らず、独立した赤/青の期待値も照合する。

追加検査で、検索を閉じる際の原稿選択喪失、Undo後のクリック位置変動、閉じた設定ペインのpaddingによる4pxの横溢れ、成功時の通知整理で破損保存の警告まで消す副作用も再現した。ハンドルを動かさず押す操作と、ルビ入力のやり直しでも、選択喪失と旧エラーの残留を失敗テストで確認して修正した。実画面の再点検では、SNS画像から本へ戻す操作が地余白と番号の衝突で拒否される問題も見つかり、同じ入力・操作で修正前に失敗する検査を加えた。本へ戻す際は天・地の余白を標準値以上へ補正する。通常の再現テストを保って修正する。ファイルメニューへの導線変更は、作品情報を開く操作をメニュー経由に更新し、フォーカスと内容の期待値は残す。

現在の操作は[UI](../UI.md)、機能と上限は[CAPABILITIES](../CAPABILITIES.md)、全体の合格条件は[ACCEPTANCE](../ACCEPTANCE.md)。この履歴自体を最新ソースの検証済み証拠として流用しない。
