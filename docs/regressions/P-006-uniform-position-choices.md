# P-006: 均一ページで同じ番号位置が重複する

## 再現と失敗

用途を「一枚・連続ページ」にしてページ番号を開くと、「小口」「ノド」を左・右と表示し直した選択肢と、もともとの左・右が重複した。柱にも、本向けの小口・ノドが残っていた。

`tests/e2e/page-controls.spec.mjs` の均一ページ操作に、番号位置が重複のない6択、柱が3択になる期待値を追加。修正前は `Expected length: 6 / Received length: 10` で失敗した。

## 修正と確認

均一ページでは小口・ノドの選択肢を隠し、物理的な左・中央・右だけを表示する。保存済みの小口・ノドは同じ物理位置の選択肢として表示するため、読み込みでページの配置を変えない。本へ戻すと小口・ノドの選択肢も戻る。

同じE2Eで番号の開始位置、開始番号、範囲例外と柱の選択肢を確認する。組版モデル・出力の座標計算は変更しない。
