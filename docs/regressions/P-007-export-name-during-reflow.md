# P-007: 再組版完了時に書き出し名の入力が戻る

## 再現と失敗

原稿を変更し、組版処理の完了前に書き出し画面でファイル名を入力する。名前を確定する `change` イベントより先に、組版の完了による画面同期が起こると、入力欄が以前の名前へ戻る。アプリ内ブラウザで名前の巻き戻りを観察した。

`tests/e2e/page-controls.spec.mjs` の原稿ツール操作へ再現手順を追加。修正前は `Expected: 組版テスト / Received: 原稿` で失敗した。

## 修正と確認

名前は入力のたびに作業状態へ反映する。入力中は空白やカーソル位置を変えず、入力確定または出力開始時に前後の空白と空名を整える。組版結果の同期でも入力を維持できる。

同じE2Eで、入力を維持したまま実際のPNGとPDFを書き出す。原稿や組版設定の変更は伴わない。
