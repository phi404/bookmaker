# P-008 文書モデルの参照と入れ子記法

2026-10-03 / model-foundation。新経路を段階的に作り、旧24テストを残して検証した。

- 初回追加8テストは未実装モジュールで失敗（32件中24合格）。実装後に全32件合格。
- `fixtures/model/nested.md` の圏点+強調+ルビは新テストで最初の要素がTextとなり失敗。独立した強調の前処理をやめ、同じInlineパーサーで親文字と注釈を一体で解析するよう修正。ルビ内部の星も本文として保持する。
- `duplicate-chapters.md` で重複章の一方が消えたときに前方IDを推測維持してしまい、Scope診断が出ず失敗。重複数が変わった要素のIDは再発番し、設定の参照を切ったまま診断する。
- `style-range.md` では明示した範囲の400ウェイトがソースの強調700に負けて失敗。基底/ソース → 範囲 → Localの順に修正し、文字を変えず解決する。

- `unsupported.json` は新形式のBookStyleで未知項目が消えることを例外未発生として検出。新形式のBookStyle・範囲・番号を厳密に検証し、ソースで再現できない重複Body Sectionも拒否する。旧Project1の互換APIは残す。

失敗は `npm run test:product` 終了コード1で観測した。修正後の36件は終了コード0。本文のハッシュや禁則期待値、画像閾値は緩めていない。最終環境とゲートの結果は [QA.md](../QA.md) と `output/verification/product.json`。この記録だけで全体の合格を示さない。
