# 印刷用PDFと項目操作の実装記録

2026-10-22の有限の実装段階。直接依頼はロードマップの継続、主要印刷所の調査、必要なトンボ/塗り足し、構成下部の移動ボタン廃止、項目メニューとアイコン操作。

## 採用した範囲

- R-64：PrintSettings、原寸を維持したTrim/Bleed/Media、任意トンボ、300/350/600dpi、RGB/DeviceGray、原本PDF/SVGの印刷時再描画、JSON/Undo/出力の接続。
- R-65：項目メニュー、タッチでも使える移動先指定、章と含まれるページのIDを保護した複製。
- R-66：共通アイコン部品と状態表示、揃え/太さ/自由ページ整列、原稿投影とUndo。

設定値や操作の正本は[CAPABILITIES](../CAPABILITIES.md)・[UI](../UI.md)・[PUBLISHING_MODEL](../PUBLISHING_MODEL.md)。この記録で重複管理しない。採用理由はD-058〜60、出典と制約は[調査](../research/2026-10-22-print-submission.md)。

## 再現して修正したもの

1. PDFの原本では分かれる600dpi相当の細線が、プレビュー画像の引き伸ばしでは消える。原本再描画を接続し、端数を切り上げて一画素分の余白が入る問題も修正した。
2. 有効な保存データで要素IDとブロックIDが同名だと、章の複製が見出し参照を取り違える。構造用のID対応と他の名前空間を分け、既存IDを避けて発番する。
3. ドラッグ用の実アイコンに置き換える際のクラス喪失で、ハンドルが見えなくなる。PC/320pxの修正前失敗を残し、操作と表示を再確認する。
4. 用紙見本と本文プレビューでSVGのIDが重複する。見本のIDを分け、詳細を閉じている間は生成しない。コマンド検索の中央揃えも新しい操作部品へ接続し直した。
5. 塗り足し付きPDFを挿入すると、正しい原寸でも判型不一致と判定される。素材の裁ち落とし幅を含めて照合し、実際に異なる判型への警告は維持した。
6. PDF設定の列挙値に配列を渡すと文字列へ変換されて検査を通る。JSONとして取り得る不正な型で失敗を再現し、型と値を両方検証する。
7. 背景組版の完了時に素材一覧が作り直され、操作中のクリック・フォーカス・管理欄を失う。Firefoxの実失敗に加え、Workerの応答を保留する再現で修正前失敗を確認した。一覧の表示値と参照数・サムネイルが同じ間は操作部品を保つ。
8. WebKitのSVG画像化で外周に透明画素が残り、RGB/灰色チャンネルへの変換で黒い線になる。通常のページ画像は先に用紙色で塗り、透明レイヤーを必要とする経路だけ透過を維持する。実PDFの白い四隅で修正前失敗を残し、両エンジンの画像データを独立に確認する。

再現fixture・修正前後のログ・画面と独立PDF解析はoutput/press-2026-10-22/。基準画像の更新は差分を個別に見て記録し、通常の比較を行う。合格の有無は現在のソース指紋と実行記録で確認する。
