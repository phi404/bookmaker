# 原稿から始めるUX改善 — 2026-10-03

**履歴資料**：この段階の計画・設計根拠を保存した文書。現行の機能は [CAPABILITIES](../CAPABILITIES.md)、操作は [UI](../UI.md)、今後の方針は [ROADMAP](../ROADMAP.md)。本文の「現在」「後続」「未実装」は当時の範囲を指し、恒久的な実装指示ではない。

最新のユーザー指摘に基づく現在の作業。Book Workspaceの機能と正本を維持し、操作順序と露出を改める。多機能化やリッチ執筆ソフトへの転換はしない。

## 操作の軸

原稿を入れる → 本文全体を整える → 必要な箇所だけ調整する。構成は唯一の入口ではない。紙面は結果を確認する場所で、対象の選択と書式変更を分ける。

## 対象

- 初回は空の「原稿」。16pxの通常フォント、折り返し、行番号なし。PC通常幅と広げる操作、スマホ全幅。
- 原稿/構成/素材は同じBook Modelを編集する。UIに「ソース」を使わない。
- パネルの開閉は各端に置き、入力位置・原稿・元幅を失わない。狭いPCは右を必要時に重ねる。
- 本文全体を常設入口にする。紙面の選択だけで置き換えず、明示した選択箇所編集で対象名と適用範囲を表示する。詳細数値は閉じて始める。
- 新規の記法とGUI挿入はMarkdown寄りに統一。`#`、`**太字**`、`*圏点*`、`---`、英語directive。ルビは既存の青空文庫記法。旧日本語記法は読み込み互換用に残す。
- 旧形式は正本ASTから新記法へ投影し、ID・書式・意味的範囲・文字を保持する。TXTの記号を勝手に見出し/強調へ変換しない。未完draftは変換せず保護する。
