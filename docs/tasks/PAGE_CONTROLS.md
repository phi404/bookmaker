# 用途に合わせたページ組版

**履歴資料**：この段階の計画・設計根拠を保存した文書。現行の機能は [CAPABILITIES](../CAPABILITIES.md)、操作は [UI](../UI.md)、今後の方針は [ROADMAP](../ROADMAP.md)。本文の「現在」「後続」「未実装」は当時の範囲を指し、恒久的な実装指示ではない。

2026-10-01の追加依頼を現在の作業範囲とする。最初のsliceは履歴として残す。

## 判断

- 見開き／一枚はプレビューの形。本／左右共通は版面の規則。互いに独立させる。
- 本は右綴じ。次の見開きへは左へ進む。一枚は上下のページ移動にする。
- 通常はプリセット、判型、文字サイズ、行間、余白だけを表示する。数値、ノンブル、柱は閉じた詳細設定に置く。
- 自動字下げは無効を標準とする。改行は段落の区切り、空白と空行は原稿の指定を尊重する（ユーザー回答で確定）。
- ノンブルの表示開始ページと開始番号は別の値。範囲で上書き／非表示もできる。柱もページ範囲で扱う。
- 本文の座標例外は追加しない。見出しの次段落保持、右／左開始、ルビと圏点は文書構造で表す。
- A6、A5、B6、寸法を明記した新書風、任意寸法に対応する。横書き・二段・表紙は今回の範囲外。
- TXT、限定したMarkdown、DOCXの本文構造、プロジェクトJSONを取り込む。Wordの版面や画像を再現するインポートではない。変換で扱えない要素は通知し、元ファイルは変更しない。
- PNGは選択ページ、範囲ZIP、見開き。PDFは範囲指定。プロジェクトJSONは編集状態を往復させる。
- 通常の長音記号「ー」を変換しない。ダッシュ「―」「—」の連続は共通SVGで連続する線にする。

## 難所と割り切り

ブラウザの縦書き字形を使い、改行・禁則・ルビ群の分割・ページ配分は純粋なTypesetterで計算する。CSSだけのページ分割と別のPDF組版を併用しない。

ルビはグループルビ。版面より長い群は親文字／読みを保持して分割する。熟語ルビ、追込み・追出しによる行の均等配置、欧文単語保持、PDFの文字化とPDF/Xは今後の改善。PDFは同じSVGからの画像PDFで、検索可能な文字や印刷所の入稿保証はない。

## 検証

先にMVP fixtureと追加の回帰テストを有効化し、未実装の失敗を確認する。内容保存、禁則、ルビ、圏点、範囲ノンブルと柱、左右共通の座標、判型を単体で検証する。実ブラウザでは取り込み→構造指定→両プレビュー→設定→保存→実PNG/ZIP/PDFをPC・スマホで検証する。新しい基準画像は目視確認と理由記録の後に採用する。
