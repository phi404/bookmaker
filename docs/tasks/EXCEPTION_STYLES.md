# 書籍の例外を扱うスタイルと操作 — 2026-10-03

**履歴資料**：この段階の計画・設計根拠を保存した文書。現行の機能は [CAPABILITIES](../CAPABILITIES.md)、操作は [UI](../UI.md)、今後の方針は [ROADMAP](../ROADMAP.md)。本文の「現在」「後続」「未実装」は当時の範囲を指し、恒久的な実装指示ではない。

最新の「次回修正要件」と、その後の「既存UIは変更してよい・別判型も対応」の指示を現在の対象とする。以前の画面を維持することは目的にしない。保存済みの原稿・正本・素材の保護、端末内処理、共通のプレビュー/出力は維持する。

## 操作の思想

原稿を入れる → 自動でできた紙面を確認する → 本文全体を整える → 必要な対象だけを選んで例外を指定する。原稿は文章用の折返し入力でありコードエディタにしない。原稿/構成/素材は、それぞれ内容・順序・資源を扱う同じBook Modelの投影。3ペインはこの役割から導き、機能を並べるためのパネルにしない。

通常の書式はBookStyleと共通スタイルで管理する。章・段落・文字の変更は適用先と件数を示し、リセットで元に戻せるようにする。紙面を選ぶ操作と、設定へ入る操作は区別し、常設の「本文全体」を追い出さない。名前付きスタイルを編集する画面は詳細から入る。

## 実装範囲

- Character / Paragraph / Heading / Page / Sectionスタイルの継承、BookStyle、明示的な局所変更。部分余白の継承を保持し、循環・未知属性・参照切れを検査する。
- 文字の太さ・サイズ・字間、4種類の圏点、ルビ、英字の正立/横倒し、数字の自動/縦中横/正立/横倒し/漢数字表示。原文は変えず、表示用の数字を生成する。
- 先頭/段落全体/末尾のインデント、揃え、前後空き、行送り、実際の次段落の大きさを考慮するKeep with next。
- 本・章・構造アンカーのPageStyle、縦書き/横書き、一段/二段、段間、字数/行数、余白、柱/番号の表示。章スタイルは開始位置・本文/版面スタイルを束ねる。
- A6/B6/A5/B5(JIS)/A4/新書風/140mm正方形、任意寸法（幅60–350mm、高さ60–500mm）。紙面の寸法は本で共通、特殊ページも同じ寸法。
- テンプレート/自由/外部ページの3種類。テンプレート変換と復帰、自由ページ内だけの整列と0–10mmスナップ。
- 画像の本文フロー/独立ページ/見開き/裁ち落とし想定/外部完成ページ。配置後の実効dpi、仕上がり寸法、元PDF寸法、塗り足し想定を生成結果に保持する。
- 「文字書式」のGUIと英語属性記法は同じASTを更新する。特殊ページの詳細と座標は原稿へ出さない。
- 適用範囲のGUIは本・章/本文セクション・選択位置から次のセクションまで。柱は通しページ範囲も指定でき、ページ一覧では疎な選択の番号/柱/紙色を変更できる。

## 今回の境界

物理ページの容量を変える書式は未対応。容量変更→改ページ→適用ページ変更の循環を避け、章/構造アンカーを使う。ページ番号が動いても範囲を構造へ勝手に置き換えない。

フロー画像の枠は現在の段の約40%で自動生成する。回り込み、キャプション、見開き画像の左右綴じ切替は未対応。裁ち落としは仕上がり外まで画像を置いて切るが、書き出すPNG/PDFは仕上がり寸法まで。塗り足しを含むPDF、文字PDF、色分解、PDF/X、正式なプリフライトは後続。フォントは同梱明朝1種類、太字はブラウザの合成。自由ページの整列は紙面に対する基本整列で、複数要素同時整列・無限キャンバスは作らない。

原稿の部分選択は同一段落内の明示的な範囲。既存の文字属性を編集する場合は指定全体を選ぶ。リッチ編集、選択のドラッグでのスタイル範囲作成、完全CommonMark、脚注・組版の全JLREQ対応は今回の対象ではない。横書き本文でも見開きの綴じは現在右綴じ。左右共通のSNS用途を選べる。
