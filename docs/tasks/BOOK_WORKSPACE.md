## 実装する経路

- 既存PublicationをBook Model v3へ拡張する。ソース・構成・Inspectorは同じAST、特殊ページ定義、素材、書式を更新する。
- 左の構成 / ソース / 素材、中央の見開き / 単ページ / 一覧、右の選択対象別Inspector。左右ペインの独立開閉・幅変更と共通Undo / Redo。
- 構成から章と特殊ページの追加・移動・削除・複製。ソースは特殊ページのID参照だけを持つ。章の現在の通しページ範囲は組版結果から導出する。
- 表題紙・章扉・目次・奥付の有限テンプレート、ページ内のテキスト・画像・線・矩形、外部PNG / JPEG / SVG / PDF。テンプレートから自由ページへの変換で意味・ID・元内容を保持する。
- 章開始の左右・次ページ指定、章と本の柱、段落の局所書式と次章までのScope。ページ一覧の複数選択で通しページに固定したノンブル / 柱 / 紙色の例外。
- 未確定の参照ソースは別のdraftに保存し、最後の有効なモデルを表示する。GUI操作で入力途中の内容を上書きしない。
- 素材を含む作業をIndexedDBへ原本と共に保存し、JSONで往復する。旧下書きは初回移行前に退避する。プレビューと同じBookPageからPNG / PDF / ZIP / 見開きを生成する。

## 今回の境界

物理ページへの容量変更は自己参照になるため、固定ページOverrideは装飾だけに限定する。本文の座標補正は作らない。自由ページは50要素まで、外部PDFは20ページ / 元16MBまで、素材合計80MBまで。目次テンプレートは1ページで、枠外・文字溢れを診断する。自動目次の自由ページ変換は項目と番号を固定する。

本文の横書き・二段組、文字選択リッチ編集、完全なPage / Section Styleカタログ、全Scope GUI、見開き画像素材、色分解 / 塗り足し / PDF/X / 文字PDFは後続段階。画像PDFを「埋め込み済み文字PDF」と表示しない。

## 検証

`fixtures/book/manifest.json` の独立原稿、モデル往復・参照draft・ID保持・特殊ページ後の改ページ・項目単位の移動・自由ページ変換・疎なページ選択・Scopeの終点を製品テストで確認する。PC / スマートフォンのGUI編集→保存→再読み込み→JSON往復と、素材のローカル読込・外部通信なし・実PNG / PDF一致をE2Eで確認する。既存R-01〜R-27は残す。画像基準の変更は差分を目視して理由を記録する。

`npm run verify:harness`、`npm run verify` と、ソース指紋に対応した手動5項目の証拠を揃える。未実行・失敗・対象外は別々に報告する。
