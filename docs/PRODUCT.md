# プロダクトの目的と境界

## 解決したいこと

Compholioは、外部で完成した原稿を、本として自然に組版し、本文・特殊ページ・画像を含む完成データまで一つのプロジェクトで扱う。最初に検証する体験は「原稿を入れるだけで、気持ちよく文庫ページができる」。

主な利用者は同人小説制作者。DTPに慣れていない人が標準設定で使え、慣れた人が必要な部分だけ調整できる。SNSへ載せる本文サンプルなど、冊子を作らない軽い用途も同じ原稿と組版から扱う。

## 主要な仕事

1. 完成原稿を貼り付ける・読み込む。読み込み後の軽微な修正を行う。
2. 自動でできた紙面を確認し、本全体の組み方を整える。
3. 章・段落・文字など意味のある対象にだけ例外を指定する。
4. 表題紙・挿絵・奥付などを必要な位置へ加える。
5. ページの流れを確認し、PNG・PDFへ出力して作業を残す。

初心者にこの五つを最初からすべて行わせない。原稿から紙面・出力までの短い経路を保ち、詳しい本づくりは必要になった時点で開ける。

## 成功の判断

標準の版面が自然で、原稿の導入が分かりやすい。設定を変えた結果がすぐ確認でき、何をどこまで変えたか分かり、元に戻せる。長文・再組版・再読み込み・書き出しで本文や設定を失わない。画面と出力は同じ組版結果を使う。

自動検査の合格、日本語組版の見た目、人間が迷わず操作できることは別の評価軸。合格条件は [ACCEPTANCE](ACCEPTANCE.md)、実行証拠は [QA](QA.md)、人間による評価の未実施範囲は [CAPABILITIES](CAPABILITIES.md) に明示する。

## 主用途にしないもの

本格的な執筆支援・校正AI・共同編集・アカウント・クラウド同期。通常本文を文字や行の座標で自由配置するDTP。Wordの見た目の完全再現、表紙デザイン、PDF本文の抽出・OCR、全印刷所への入稿保証。

自由ページ・外部完成ページは本文の自動組版を補う方式として扱う。書式や特別なページのために別プロジェクト・別の正本文書を作らない。
