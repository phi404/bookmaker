# 原稿の記法と交換形式

## 原稿ビューの役割

画面では「原稿」と呼ぶ。本文・見出し・構造の位置を文章として編集し、同じBook Modelへ反映する。文字列は編集・交換用の投影と元表現のキャッシュで、正本ではない。構成やGUIから更新すると同じ原稿へ反映する。

Markdownは**限定した対応部分**で、完全なCommonMarkではない。標準構文で表せるものを優先し、日本語組版固有の注釈と珍しい指定だけ拡張する。現在のASTの契約は [PUBLISHING_MODEL](PUBLISHING_MODEL.md)。

## 通常の記法

| 入力例 | 扱い |
| --- | --- |
| 改行 / 空行 | 次の段落 / 空き段落。入力した空白を保持 |
| `# 第一章` / `## 節` / `### 小見出し` | 意味を持つ見出し。H1が章Sectionを開始するが、見出しだけで自動改ページしない |
| `**言葉**` | 太字 |
| `*言葉*` / `***言葉***` | 圏点 / 太字と圏点。横組の斜体とは解釈しない |
| `> 引用` | 引用の段落スタイル |
| 独立行の `---` | 明示改ページ。`===` / `***` も互換記法 |
| `｜薔薇《ばら》` / 半角の縦棒 | グループルビ。親文字と読みを構造として保存 |
| `[言葉]{.dot}` / `.circle` / `.triangle` | 丸 / 白丸 / 三角の圏点。ゴマはemphasis |
| `\` + 記号 | 記法として解釈せず文字として保持 |

`:::center` / `:::end` と閉じ行 `:::` は中央/末尾揃え。縦書きでは末尾が下になる。

```text
# 第一章

　｜雨音《あまおと》を聞いた。これは**強調**です。

---

:::center
中央に置く文章
:::
```

通常のURLのコロンを逃がす必要はない。三連バッククォート内は本文記法を解釈せず保持する。リスト・リンク・表・標準Markdown画像・表・リンク等は構造化しない。書式の囲みは入れ子も読み取り、内側の同じ属性が優先する。未知・壊れたルビや不明属性は原文として残す。

## 文字の局所指定

同一段落の選択を「文字」から編集しても、この記法と同じASTを更新する。既存の指定を編集する場合は指定全体を選ぶ。

```text
[HTML]{orientation="upright"}
[abc]{orientation="sideways"}
[12]{numbers="tcy"}
[2026]{numbers="kanji"}
[強調]{fontPt="12" letterSpacingEm="0.1"}
```

属性は英語名に統一する。未対応の属性を都合のよい一部だけ適用せず、記法全体を本文として保つ。数字の表示変換で元の数値文字列を変えない。文字属性の数値と向きの範囲は [CAPABILITIES](CAPABILITIES.md)、描画規則は [TYPOGRAPHY](TYPOGRAPHY.md)。

## 範囲と章の書式

GUIの揃え・字下げ・空き・文字指定は同じ局所書式を編集し、原稿へ投影する。連続する同じ書式の段落は一つの囲みで表示する。囲みの削除は局所指定を解除し、別の隠れた属性から復活させない。名前付きスタイルの値は作業JSONのカタログで共有し、原稿はそのIDを参照する。

```text
:::format alignment="center" beforeEm="1" fontPt="12"
｜薔薇《ばら》を読む。
二行目。
:::

:::format style="quote" page.writingMode="horizontal-tb"
横書きの手紙。
:::

:::section start="recto" paragraphStyleId="body" page.margins.topMm="22"
# 次の章
章の本文。
```

formatの段落属性はalignment/indentEm/insetEm/endInsetEm/beforeEm/afterEm/lineHeight/keepWithNext、文字属性はfontWeight/fontPt/letterSpacingEm/orientation/numbers/emphasis。版面はpage.属性、部分余白はpage.margins.辺、名前付き参照はstyle/pageStyle。sectionにはstart/style/pageStyleId/paragraphStyleIdと同じ段落・文字・版面属性を使う。section指定は章見出しまたは先頭本文セクションの直前に置く。

既知の囲みの未完・不正な数値・未知のスタイル参照はsourceDraftで保護する。部分だけ適用したり、復元できない確定モデルを自動保存したりしない。

## 改ページ・特殊ページの参照

```text
:::recto

:::page-break side="right"

:::illustration id="illust-01"

:::colophon id="colophon-main"
```

rectoは改丁で、奇数通しページ（右綴じは左、左綴じは右）から始める。必要な白ページを実ページとして出力する。左右開始は本の綴じと論理ページに従う。左右共通用途では次のページ先頭として扱い、偶奇合わせの白ページは入れない。原稿の指定自体は残す。

特殊ページは `title` / `chapter-title` / `toc` / `colophon` / `illustration` / `free` / `external` とIDの参照。**何がどこに存在するか**を記述する。内容・テンプレート・素材・座標はBook Modelに別途保持し、設定から編集する。参照行を移動しても同じIDの詳細を失わない。

参照先が未確定・重複・不整合の既知記法は `sourceDraft` に保存する。最後の有効モデルと紙面を保ち、GUIによる上書きや書き出しを止めて確定を案内する。不明な構文の原文保持と、既知参照の不整合は別の扱い。

## 入出力の違い

| 形式 | 取り込み/書き出しの契約 |
| --- | --- |
| TXT | UTF-8 / UTF-16 / Shift_JIS等を判定。旧テキスト解釈で読み、Markdownの`#`/星を勝手に構造化しない。ASTから原稿へ投影する際に記法衝突だけ保護 |
| Markdown | 上記の対応部分を構造化。原表現を投影キャッシュに保持。全体のスタイル・素材はこれだけでは交換できない |
| DOCX | WordprocessingMLの段落・見出し・ルビ・圏点・手動改ページを取り込み。版面/フォント/自動改ページを再現せず、画像・注など未対応を通知。変更履歴/外部実体は拒否 |
| 作業JSON | 正本AST、全スタイル/Scope/柱/番号、特殊ページ、素材、物理Override、未完draft、表示状態を保存。schemaVersion 3、旧1/2を検証して移行 |

TXT/Markdownは本文と対応構造の交換用。特殊参照の詳細を含む完全な作業保存はJSONを使う。読み込んだ元ファイルへ自動で書き戻さない。キャッシュとASTが食い違うJSONは検証済みASTから投影を再生成し、未知の保存構造・循環スタイルは拒否する。

## 互換性・正規化

原稿ビューの読み方切替は撤去し、Markdownへ一本化する。旧作業JSONとTXT/DOCXを取り込む境界では、従来の意味を失わない変換を保持する。Markdownの日本語見出し/改ページ記法は普通の文字として扱う。旧ASTを先に読み、文字・ID・書式を保って投影する。未完draftは勝手に変換しない。

先頭BOM除去とCRLF/CR→LFだけを明示して正規化する。終端改行は入力に保持し、余分なページを作らない。NFC等のUnicode正規化、制御文字の削除、原稿への自動全角空白の挿入はしない。表示上の折返しも保存上の改行へ変換しない。

## 文字位置の対応

紙面からの移動と本文検索は、この文書の同じ解析規則から位置を生成する。記法の区切りを本文の文字数へ混ぜず、未知/不正の文字記法は従来通りリテラルとして対応づける。元入力のBOM/CRLF/CRと画面上の位置を区別し、位置取得だけで原稿を書き換えない。本文の検索は原稿表現を対象にし、ルビの読みや書式の文字列も検索できる。GUIの再投影が必要ない変更で既存の元記法を不用意に再生成しない。

## 章の番号と段落分割

章の開始番号・番号形式は既存のsection指定へ投影する。

```md
:::section numberStart="1" numberFormat="roman" start="next"
# 前書き
前付の文章。
:::section numberStart="1" numberFormat="decimal" start="recto"
# 本文
本文の文章。
```

範囲の段落分割は `:::format orphans="2" widows="2"` と閉じ行 `:::` で指定できる。GUIも同じ値を投影する。総ページ数の調整・図の説明は本/素材のモデルに保存し、原稿へ座標や詳細を埋めない。制作データZIP（.compholio.zip）は通常のファイル読み込みから再開でき、book.jsonを正本として検証する。旧名称の .folaxis.zip も読み込める。

NBSP・Word Joiner・ZWSP・結合文字を入力のまま保つ。U+2028/U+2029は段落内の明示行区切りとして組版し、LFや空白へ置換せずJSON/原稿に保存する。書式の境界だけを理由に単語を分けない。


印刷用PDFの設定は作業JSONのBook Modelに保存する。塗り足し・トンボ・出力解像度を原稿の囲み記法や本文の余白へ投影しない。原稿ファイルの本文は変わらない。詳細は[PUBLISHING_MODEL](PUBLISHING_MODEL.md)。
